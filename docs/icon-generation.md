# Иконка Adrobot

Создана встроенным инструментом `image_gen` (навык `imagegen`), без CLI/API fallback.

Исходник: `assets/adrobot-icon-source.png`. Рабочие версии: `../frontend/public/brand/adrobot-icon.png` (192×192) и `../frontend/public/brand/favicon-32.png` (32×32). Уменьшены системным `sips`, без изменения дизайна. Большая версия используется в шапке и как touch icon, маленькая — как favicon. Иконка декоративная в шапке (`alt=""`), поскольку рядом есть название приложения.

Точный промпт:

> Use case: logo-brand. Create a single square website app icon for Adrobot, a campaign management application. Minimal bold geometric robot face subtly shaped like the letter A, two clean square eyes and a simple arch silhouette, distinctive professional mark. Flat two-color palette: deep forest green #152b24 and pale lime #d7f3bd matching its existing dashboard. Solid deep forest green square background filled edge to edge, lime central mark with generous 15% safe padding. Crisp flat edges, strong silhouette recognizable at 32px. No text or wordmark, no gradients, no mockup, no shadows, no fine lines. Output just one finished square icon.
